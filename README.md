# My Portfolio

A simple personal portfolio website built with HTML. It showcases basic information about the developer, featured projects, and contact details in a clean single-page layout.

## Overview

This project includes:
- a hero/header section with the developer's name
- an About Me section
- a Projects section listing sample work
- a Contact section with email and phone details
- navigation links to different sections of the page

## Project Structure

```text
Aren Project/
├── index.html
├── main.css   # Expected stylesheet referenced by the page
└── README.md
```

## How to Run

1. Open the project folder in your browser or code editor.
2. Launch `index.html` directly in a browser.
3. If you are using a local web server, you can also run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Customization

You can update the following in `index.html`:
- name and title
- About section content
- project list
- contact email and phone number
- navigation links

## Notes

The page references a stylesheet named `main.css`. If that file is not present in your project folder, add a CSS file with that name or update the link in the HTML to match your styling file.
